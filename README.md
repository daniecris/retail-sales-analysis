# retail-sales-analysis
Retail sales data analysis using SQL and PostgreSQL

Project overview
This project focuses on analyzing retail sales data using SQL and PostgreSQL to identify sales trends, evaluate product performance, and generate business insights.
The goal is to explore sales data and answer key business questions that can support data-driven decision-making 

Tools used
* PostgreSQL
* SQL
* pgAdmin

Dataset Overview 
The dataset contains 20 sales transactions with the following columns:
- sales_id
- sale_date
- product
- category
- quantity
- unit_price
- region

SQL Analysis 
The project includes the following analyses:
1. Total revenue
2. Total units sold
3. Average unit price
4. Highest and lowest unit price
5. Revenue by product category
6. Revenue by region
7. Top products by region
8. Best selling products by quantity

Key business insights 
- Total revenue: $9,517.39
- Total units sold: 101
- Average unit price: $204.32
- Highest unit price: $899.99
- Lowest unit price: $1.50
- Sales by product category: Top performing category: Electronics $6,879.78, lowest performing category: Stationery: $187.78
- Sales by region: Top performing region: North $6,049.85, lowest performing region: East $727.79
