# retail-sales-analysis
Retail sales data analysis using SQL and PostgreSQL
Project overview
This project focuses on analyzing retail sales data using SQL and PostgreSQL to identify sales trends, evaluate product performance, and generate business insights.
The goal is to explore sales data and answer key business questions that can support data-driven decision-making 

Tools used
* PostgreSQL
* SQL
* pgAdmin

Dataset Overview 
The dataset contains 20 sales transactions with the following columns:
- sales_id: Unique identifier for each sale
- sale_date: Date of the transaction 
- product: Product name
- category: Product category
- quantity: Number of units solf
- unit_price: Price per unit 
- region: Sales region
